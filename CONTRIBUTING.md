# Contributing

Use fictional data only. Never include family memories, media, private links, provider keys, or credentials in issues, examples, screenshots, or tests.

Keep changes focused. Add meaningful regression tests for authorization, storage, AI, or migration changes. Run `npm run format:check`, `npm test`, `npm run build`, and relevant integration checks before opening a pull request.

Migrations must remain additive and repeatable. Check desktop, phone, keyboard, and a full recording-to-story flow for interface changes. Contributions are MIT licensed.
